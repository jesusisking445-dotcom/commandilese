COMMAND DAY SECONDARY SCHOOL, IJEBU ODE - DEPARTMENT TEST
=========================================================

OPEN THIS FILE:   index.html      (double-click it; works offline and on the web)

FOLDER CONTENTS
  index.html            The test app. Loads its questions from the "questions" folder.
  questions/            One file per subject. Edit these in Notepad to change or add questions.
  department-test.html  A one-file copy of the same app with a small built-in sample
                        question set. Use it only if you need a single file to share.
                        Editing questions/ does NOT change this copy.

TO CHANGE: school name, teacher PIN (default 1234), timing -> open index.html in Notepad
and edit the CONFIG block near the top.

Keep index.html and the "questions" folder together in the same place.
